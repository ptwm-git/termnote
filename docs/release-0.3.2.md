TermNote 0.3.2 修复重复粘贴，并增加关闭取舍和缺失序号回填。

- 从外部粘贴命令只输入一次；自动保存间隔不执行按键。
- 点击标签 ×，可选「保存并退出 / 不保存 / 取消」。保存会结束终端并保留全部记录；不保存会结束终端，将该生成备份按 Obsidian 设置移入回收站，并清理该会话日志；与历史原件共享的归档会保留。取消保持不变。来源原文与其他标签不受影响；无法确认归属的历史文件只提供保留。
- 默认命名使用所在目录最小空缺序号，例如删掉二、三后优先新建二、三。复用的是名称，新会话使用新的 ID。
- 标签右键仍可收起并后台保存；关闭整个工作台继续后台运行。保持右侧上下分栏、独立外观及增量对话记录。

需要 Obsidian 桌面端 1.14.4+、Python 3.9+，Windows 还需同一解释器安装 pywinpty。仅支持 macOS / Windows，CLI 自行安装登录。macOS Obsidian 实测与 Windows CI 范围详见仓库验证记录；Windows Obsidian 图形界面仍待人工试用。

在 Obsidian 第三方插件中检查更新，或通过 BRAT 仓库 `ptwm-git/termnote` 更新。手动安装可使用 ZIP 内的 `agent-note-terminal` 文件夹。发行文件由 CI 构建并提供来源证明及 SHA256SUMS。
