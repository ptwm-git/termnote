TermNote 0.3.1 将新建记录改为增量对话流，减少终端重绘带来的重复内容。

- 提交的可见输入标为「我」，程序输出标为「终端」，菜单确认标为「操作」。输入草稿和回显合并，不逐字生成笔记。
- 流式回答更新当前输出块；模型列表高亮、常见加载动画和同步刷新不反复保存整屏。保留真实重复输出及不同轮次相同回答。
- 旧笔记原文保留。旧标签的「更多操作 → 生成精简记录副本」会在同目录生成新文件，原件和原始日志不变；缺失或损坏日志不能作为完整来源。继续旧增强会话也先另建文件。
- 保持右侧上记录、下系统终端，多标签及上下独立配色。直接输入任意已安装 CLI，不默认绑定 Agent。

需要 Obsidian 桌面端 1.14.4+、Python 3.9+；Windows 还需同一解释器的 pywinpty。仅支持 macOS / Windows。CLI 自行安装和登录。

已在 macOS Obsidian 的普通 Shell 内实际运行 OpenCode 2.0.26，通过隔离环境和本地模拟模型验证增量对话。Windows ConPTY/PowerShell 与 OpenCode 协议由 CI 验证；Windows Obsidian 图形界面仍需人工试用。

通用终端依据屏幕内容整理，未知程序可能保留界面文字或无法识别输入框；不承诺任意 Agent 的完整语义角色或原生上下文恢复。原始日志保存终端输出，仍可能包含程序回显的草稿或敏感内容，分享前请检查。

在 Obsidian 第三方插件中检查更新，或通过 BRAT 仓库 `ptwm-git/termnote` 更新。手动安装可将 ZIP 内的 `agent-note-terminal` 文件夹放入知识库 `.obsidian/plugins/`。三个标准运行文件由 CI 构建并提供来源证明，SHA256SUMS 用于校验。
