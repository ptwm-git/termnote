TermNote 0.3.3 修复字体裁切，并合并粘贴和页面管理调整。

- macOS默认字体下，终端默认行高改为1.3，中文笔画显示完整；主题字体变化重新测量，光标/选区/终端尺寸统一适配。字号和上下独立配色继续使用原设置。
- 外部命令粘贴只输入一次，500ms间隔只用于自动保存。
- 点击标签×选择「保存并退出 / 不保存 / 取消」。保存等待尾部记录落盘；不保存停止实例，将生成备份按Obsidian设置移入回收站，并清理独立日志。来源原文及其他标签保持；旧继续副本与原件共享的归档保留。
- 默认名称优先补齐所在目录最小空缺序号，新建使用新会话ID。
- 工作区就绪后再恢复历史，避免冷启动时误判文件缺失；升级不自动运行命令。

0.3.2草稿构建后收到字体反馈，统一以0.3.3交付。

需要Obsidian桌面端1.14.4+、Python3.9+；Windows还需同一解释器安装pywinpty。仅支持macOS/Windows，CLI自行安装登录。macOS Obsidian实测与Windows CI范围详见仓库验证记录；Windows Obsidian图形界面及原生剪贴板仍待人工试用。

在Obsidian第三方插件中检查更新，或通过BRAT仓库 `ptwm-git/termnote` 更新；手动安装可用ZIP内的 `agent-note-terminal` 文件夹。CI发行文件提供来源证明与SHA256SUMS。
