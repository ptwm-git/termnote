TermNote 0.3.4：每标签笔记同步开关与安全恢复。

- 文件名右侧首个工具栏操作为「同步 ON/OFF」，每标签独立、默认ON，状态及边界持久化。OFF终端继续运行，笔记/预览保持；再ON不补录OFF期间内容，停止/导出也不补写。原始终端日志仍保存，开关不是隐私擦除。
- 红字冲突可点击同步按钮恢复：确认后先在同目录保存完整可读副本，再原子恢复当前会话区域，区域外文字保留。取消、绑定/边界改变、日志不完整或备份/写入失败均保留现有内容并报错。
- 上方展示真正已保存内容；同文件多编辑器同步更新，内容分叉时拒绝覆盖。
- 排除底部块状加载/快捷键统计重复，修复长句换行重排重复，保留真实重复和跨轮相同回答。
- 旧记录升级加载/退出保持原件，历史增强会话保留既有行为；使用「＋」新建系统终端可使用开关。

需要Obsidian桌面端1.14.4+、Python3.9+；Windows还需同一解释器安装pywinpty。仅支持macOS/Windows，CLI自行安装登录。Windows Obsidian图形界面及原生剪贴板仍待人工试用，实际验证范围见仓库验证记录。

在Obsidian第三方插件中检查更新，或通过BRAT仓库 `ptwm-git/termnote` 更新；CI提供标准三文件、手动ZIP、来源证明和SHA256SUMS。
